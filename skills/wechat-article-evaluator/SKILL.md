# 微信公众号文章质量评估器 (wechat-article-evaluator)

## 触发条件

- 评估文章, 文章打分, 文章质量评估
- 公众号文章评分, 爆文评估
- /wechat-article-evaluator <文件路径>
- 这篇文章能爆吗, 文章能打多少分

## Instructions

### Step 1: 获取文章内容

- **文件路径**: `.md` 或 `.txt` 文件 → 使用 Read 工具读取
- **内联文本**: 用户直接粘贴的文章内容
- **无输入**: 提示用户提供文章内容或文件路径

### Step 2: 预分析

快速扫描文章基本信息：

| 检查项 | 说明 |
|--------|------|
| 标题 | 提取文章标题（首行 # 或第一行） |
| 字数 | 统计全文字数 |
| 段落数 | 统计段落结构 |
| 目标受众 | 根据内容推断目标读者群 |

### Step 3: 五维度评分

逐一评估以下 5 个维度，每个维度 20 分，总分 100 分。
详细评分标准见下方「评估维度」章节。

### Step 4: 生成评估报告

按照「输出格式」章节的模板输出完整报告，包含：
- 总分与等级
- 各维度详细评分（含进度条）
- 综合评价
- 具体改进建议（至少 3 条可操作建议）

## 质量等级

| 等级 | 分数 | 说明 |
|------|------|------|
| A+ | 90-100 | 爆文潜质 |
| A | 80-89 | 优质文章 |
| B | 70-79 | 合格文章 |
| C | 60-69 | 需要改进 |
| D | 50-59 | 较差 |
| F | <50 | 需要重写 |

## 评估维度

### 总分 100 分，5 个维度

| 维度 | 满分 | 核心关注 |
|------|------|---------|
| 标题吸引力 | 20 | 记忆锚点、好奇心触发、简洁有力 |
| 情绪共鸣 | 20 | 真实感、打动人、代入感 |
| 结构完整性 | 20 | 逻辑通顺、节奏合理、首尾呼应 |
| 案例深度 | 20 | 具体细节、说服力、真实经历 |
| 爆文潜力 | 20 | 传播性、分享欲、受众匹配 |

### 维度 1: 标题吸引力 (20分)

| 子项 | 分值 | 评分标准 |
|------|------|---------|
| 记忆锚点 | 7 | 标题是否包含具体数字/人物/场景，让人过目不忘。7=画面感极强，4=有亮点，2=平淡 |
| 好奇心触发 | 7 | 是否制造信息差/悬念/反常识。7=非点不可，4=有点想看，2=无感 |
| 简洁有力 | 6 | 字数15-25字为佳，无废字，节奏感好。6=精炼有力，3=略冗长，1=拖沓或过短 |

### 维度 2: 情绪共鸣 (20分)

| 子项 | 分值 | 评分标准 |
|------|------|---------|
| 真实感 | 7 | 是否有真实的情感表达，非套路化鸡汤。7=真诚动人，4=尚可，2=假大空 |
| 打动力 | 7 | 能否触发读者情绪（感动/愤怒/共鸣/启发）。7=强烈共鸣，4=有触动，2=无感 |
| 代入感 | 6 | 读者能否把自己代入场景。6=身临其境，3=部分代入，1=旁观者视角 |

### 维度 3: 结构完整性 (20分)

| 子项 | 分值 | 评分标准 |
|------|------|---------|
| 逻辑通顺 | 7 | 段落间因果/递进/转折是否自然。7=行云流水，4=基本通顺，2=跳跃混乱 |
| 节奏合理 | 7 | 长短段交替、张弛有度、不拖沓。7=节奏感强，4=尚可，2=平铺直叙 |
| 首尾呼应 | 6 | 开头吸引+结尾升华，形成闭环。6=完美闭环，3=有头有尾，1=虎头蛇尾 |

### 维度 4: 案例深度 (20分)

| 子项 | 分值 | 评分标准 |
|------|------|---------|
| 具体细节 | 7 | 案例是否有时间/地点/人物/对话等细节。7=细节丰满，4=有细节，2=笼统空泛 |
| 说服力 | 7 | 案例能否有力支撑观点。7=无可辩驳，4=有说服力，2=牵强附会 |
| 真实经历 | 6 | 是否来自真实经历或可信来源。6=亲身经历，3=二手可信，1=编造感强 |

### 维度 5: 爆文潜力 (20分)

| 子项 | 分值 | 评分标准 |
|------|------|---------|
| 传播性 | 7 | 内容是否自带传播属性（争议/共鸣/实用）。7=必转，4=想转，2=不想转 |
| 分享欲 | 7 | 读者转发时能否获得社交货币。7=转发涨身份，4=值得分享，2=无分享动力 |
| 受众匹配 | 6 | 内容与目标受众的匹配度。6=精准命中，3=部分匹配，1=受众模糊 |

### 附加维度: 人味指数 (满分 10，不计入100分基础分)

独立于 5 大维度之外的 AI 味检测指标，用于判断文章是否像人写的。

| 子项 | 分值 | 评分标准 |
|------|------|---------|
| 个人化表达 | 4 | 是否有"我"的视角、个人经历、独特比喻。4=强烈个人风格，2=有一些，0=纯客观 |
| 语言自然度 | 3 | 是否像人说话而非AI输出。3=口语化自然，2=书面但不僵硬，0=明显AI腔（模板句式、对称结构） |
| 不可预测性 | 3 | 段落走向是否有意外。3=多处意外转折/自嘲/跳跃，2=偶有惊喜，0=完全可预测的总分总 |

**AI味检测要点**:
- 禁用词命中：赋能/助力/深度/维度/底层逻辑/认知升级/不可否认/毋庸置疑/众所周知
- 模板句式：首先...其次...最后、一方面...另一方面
- 对称结构：连续段落句式雷同
- 元评论：总之/综上所述/让我们一起

**警告线**: 人味指数 < 5 时，报告中标注 `⚠️ AI味偏重`

## 质量门禁模式 (v2.0 新增)

### --gate 模式

当使用 `--gate` 标志调用时，切换为质量门禁模式：

- 返回 **pass/fail 判定**，而非仅评分
- 通过标准：`total >= 90` 且 `title_score >= 20`
- 输出包含结构化 `fix_instructions`，每条建议足够具体，可直接喂给 AI 执行修改

输出格式：

```
╔══════════════════════════════════════════╗
║         质量门禁检查结果                    ║
╠══════════════════════════════════════════╣
║ 总分: 88/100    标题: 17/20              ║
║ 判定: ❌ FAIL                            ║
║ 原因: 总分 < 90, 标题 < 20               ║
╠══════════════════════════════════════════╣
║ 修复指令 (按优先级排序):                    ║
║ [P1] 标题: 当前17→目标20                  ║
║   → 标题缺乏反转结构，建议加入数字锚点...    ║
║ [P2] 案例: 当前17→目标18                  ║
║   → 第二个案例缺少时间地点细节...            ║
╚══════════════════════════════════════════╝
```

### --title-only 模式

仅评估标题维度（20 分），用于标题独立迭代。

输出内容：
- 标题维度评分（3 个子项详细分数）
- 3 个改进候选标题及预测分数

```
标题评估: 「我在大厂3年，终于明白了一个道理」 → 15/20

候选改进标题:
  1. 「大厂3年，我发现升职最快的人只做一件事」 → 预测 18/20
  2. 「在大厂熬了3年，我终于看懂了晋升的潜规则」 → 预测 19/20
  3. 「3年大厂经历，我总结出1条反常识的职场真相」 → 预测 17/20
```

## 门禁循环协议

本节描述评估器在管线中的循环工作方式。

### 轮次追踪

- 接受 `--round N` 参数，标记当前为第 N 轮评估
- 报告中显示轮次信息：`[Round N]`
- 多轮评估时自动对比前后分数变化

### Diff 感知

- 当接收到前一版本内容时，高亮标注变更部分
- fix_instructions 中标注哪些是"已修复"、哪些是"仍需改进"
- 避免重复给出已修复维度的建议

### fix_instructions 优先级规则

- 优先级 = 该维度距离目标分数的差距（差距越大优先级越高）
- 目标分数：总分目标 90，标题目标 20
- 同等差距时，标题维度优先于其他维度

### 标题与正文分离策略

- 当正文维度总分 >= 72（即非标题4维度均分 >= 18）但标题 < 20 时：
  - fix_instructions **仅**针对标题
  - 明确标注"正文质量已达标，仅需优化标题"
- 当标题已满分但总分不足时：
  - fix_instructions 排除标题维度

## 使用示例

```bash
# 评估 Markdown 文件
/wechat-article-evaluator ~/articles/my-post.md

# 评估粘贴的文章内容
/wechat-article-evaluator
（然后粘贴文章内容）

# 精简模式
/wechat-article-evaluator --summary ~/articles/my-post.md

# 评估并给出改写建议
/wechat-article-evaluator ~/articles/draft.md --rewrite-tips

# 质量门禁模式
/wechat-article-evaluator ~/articles/my-post.md --gate

# JSON 输出（供管线消费）
/wechat-article-evaluator ~/articles/my-post.md --gate-json

# 仅评估标题
/wechat-article-evaluator ~/articles/my-post.md --title-only

# 门禁模式 + 轮次追踪
/wechat-article-evaluator ~/articles/my-post.md --gate --round 2
```

输入标题: 「我在大厂 3 年，终于明白了一个道理」


## 评估原则

1. **严格但公正**: 不因篇幅长短偏袒，短文也能得高分
2. **对标爆文**: 以10w+阅读量的公众号文章为标杆
3. **可操作建议**: 每条改进建议必须具体到可以直接修改
4. **场景感知**: 不同类型文章（观点/教程/故事）适用不同侧重

---

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 未提供文章内容 | 提示: "请提供文章文件路径或直接粘贴文章内容" |
| 文件不存在 | 提示: "文件 {path} 不存在，请检查路径" |
| 内容过短 (<100字) | 提示: "文章内容不足100字，无法进行有效评估，请提供完整文章" |
| 非中文内容 | 提示: "本工具针对中文公众号文章优化，英文内容评估可能不准确" |
| 无标题 | 使用首行作为标题，标注"未检测到明确标题" |

---

## 边界情况

| 场景 | 处理策略 |
|------|---------|
| 纯干货教程类 | 情绪共鸣维度适当放宽，侧重结构和案例 |
| 纯情感故事类 | 案例深度侧重真实感和细节，非论证说服力 |
| 短文 (<500字) | 正常评估，但在报告中标注"短文模式" |
| 长文 (>5000字) | 正常评估，额外关注节奏和结构 |
| 列表体/清单体 | 结构完整性侧重逻辑分类，非叙事节奏 |
